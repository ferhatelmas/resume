# Ferhat Elmas resume

The canonical source is
[`ferhat-elmas-resume.tex`](ferhat-elmas-resume.tex), with a compiled PDF at
[`ferhat-elmas-resume.pdf`](ferhat-elmas-resume.pdf).

## Build

Install [Tectonic](https://tectonic-typesetting.github.io/) and compile from the
repository root:

```sh
tectonic ferhat-elmas-resume.tex
```
